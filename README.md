# Ixora: Hotel Management System

Full-Stack web application designed to manage hotel room bookings, users, and additional services.

![Ixora Project Demo](ixora.gif)

### Demo
- **Frontend:** [https://m0ndares.github.io/ixora/front/3/menu.html](https://m0ndares.github.io/ixora/front/3/menu.html)
- **Backend API:** [https://ixora-4tb9.onrender.com](https://ixora-4tb9.onrender.com)

### Architecture
- **Frontend:** HTML5, CSS3, JavaScript 
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL 
- **Hosting:** GitHub Pages, Render

### Libraries
* `@supabase/supabase-js` 
* `cors` 
* `express` 
* `dotenv`
